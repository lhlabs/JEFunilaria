# Imagens do site JCE

Envie os arquivos abaixo para esta pasta, mantendo exatamente estes nomes:

- `logo.png` — logomarca exibida no cabeçalho.
- `foto1.jpg` até `foto6.jpg` — imagens da galeria e serviços.

O site já usa os caminhos relativos `imagens/logo.png` e `imagens/foto1.jpg` a `imagens/foto6.jpg`.

Dica: prefira fotos em JPG otimizadas para web, com até 2 MB cada, para o site abrir rapidamente.
